# ISMS Quick Start Guide
## Get Started in 5 Minutes

---

## For School Administrators

### Step 1: Register Your School (5 minutes)

1. Go to login page
2. Click **"Register New School"**
3. Fill in:
   - School name
   - Email and phone
   - Principal details
   - Location
4. Submit registration
5. Check email for activation

### Step 2: Set Up Your School (10 minutes)

1. **Add Classes**
   - Go to **Classes** → **Add Class**
   - Create classes (Grade 1, Grade 2, etc.)
   - Add sections (A, B, Morning, etc.)

2. **Add Staff**
   - Go to **Staff** → **Invite Staff**
   - Send invitations to teachers
   - Assign roles and permissions

3. **Configure Fees**
   - Go to **Fee Management** → **Fee Structures**
   - Create fee categories
   - Set amounts and due dates

### Step 3: Add Students (15 minutes)

1. Go to **Students** → **Add Student**
2. Fill in student information
3. Assign to class and section
4. Repeat for all students

**Tip:** Use bulk import for multiple students

### Step 4: Start Using (Daily)

1. **Mark Attendance** - Every morning
2. **Check Messages** - Throughout the day
3. **Record Payments** - As received
4. **Generate Reports** - Weekly/Monthly

## For Teachers

### First Login

1. Check email for invitation
2. Click invitation link
3. Set password
4. Log in

### Daily Tasks

1. **Mark Attendance**
   - Go to **Attendance**
   - Select your class
   - Mark present/absent
   - Save

2. **Create Assignments**
   - Go to **Assignments**
   - Click **"Create"**
   - Fill in details
   - Publish

3. **Grade Assignments**
   - Go to **Assignments**
   - View submissions
   - Enter grades
   - Add feedback

4. **Check Messages**
   - Go to **Messaging**
   - Read and respond
   - Send announcements

## For Parents

### Accessing Parent Portal

1. Receive login credentials from school
2. Log in to system
3. View child's dashboard

### What You Can Do

1. **View Child's Information**
   - Attendance
   - Grades
   - Assignments
   - Timetable

2. **Pay Fees**
   - Go to **Fee Management**
   - View invoices
   - Pay online (Easypaisa, JazzCash, Card)

3. **Communicate**
   - Send messages to teachers
   - Receive announcements
   - View circulars

4. **View Reports**
   - Attendance reports
   - Grade reports
   - Fee statements

## Common Tasks - Quick Reference

### Adding a Student
**Students** → **Add** → Fill form → **Save**

### Marking Attendance
**Attendance** → Select class → Mark → **Save**

### Creating Invoice
**Fee Management** → **Invoices** → **Generate** → Select students → **Generate**

### Recording Payment
**Fee Management** → **Payments** → **Record** → Enter details → **Save**

### Creating Exam
**Examinations** → **Create** → Fill details → **Save**

### Entering Grades
**Examinations** → Select exam → **Enter Grades** → Fill marks → **Save**

### Sending Message
**Messaging** → **New Message** → Select recipient → Type → **Send**

### Generating Report
**Reports** → Select type → Set filters → **Generate** → **Export**
